# 社区助手与演示数据扩充

日期：2026-09-07。本轮范围为真实模型接入、业主功能查询与问答、社区规模演示数据，以及物业账单明细。整体检查依照当前安排留到后续，本轮只验证相关模块。

## 接入与交互

原启动器使用本机 9100 端口的规则模拟服务。现已确认本机保存的 BuffLink 配置提供 Responses 接口，模型列表包含 `gpt-6-astra`，一次小型 JSON 生成请求返回成功。应用采用该配置的服务端密钥，不向浏览器暴露凭据；模型名称代表网关配置及返回的模型标识。

业主新增“社区助手”，分为智能问答和功能查询。问答结合当前业主可见的账单、报修、预约、房屋以及本社区已发布公告，支持多轮提问；功能目录可以直接搜索和进入业务页面。助手只读数据，不代替业主提交、缴费或物业审批。

## 数据规则

新增多栋楼、合成住户、多类别账单、完整状态工单、分区车位、停车审批记录和社区公告。生成器只增补一个版本的数据，不覆盖已有付款、取消、编辑和审批结果。基础小型测试数据保留，扩充数据由演示启动参数显式启用。

演示规模不等同于生产容量验证；本轮不宣称完成并发容量、支付网关或真实停车设备验证。

## 已执行验证

问答及模型协议定向测试通过；社区数据生成、迁移、账单查询及相应前端组件分别执行定向测试。实际网关问答核对了17笔未缴、合计1534.54元的统计；两项草稿生成成功。按当前安排，源码先同步到GitHub，全量测试与全流程回归留到后续统一执行。

页面定向运行确认包括真实问答的桌面/手机显示、功能目录、物业账单20条分页、工单20条分页及单区24个车位的展示，未出现页面运行错误。再次启动时同一数据批次的新增数量均为0。

真实调用的单次观测耗时为：费用问答7.51秒、报修整理8.17秒、公告拟稿7.88秒。这些是本轮样本，不是性能承诺或整体容量测试。桌面1024 x 768和手机390px宽度的助手页面已做定向显示确认。
